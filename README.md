# 🃏 暗記カード — 間隔反復学習アプリ

[Anki](https://apps.ankiweb.net/) を参考にした、ブラウザだけで動く暗記アプリです。
インストール・ビルド不要で、`index.html` を開くだけで使えます。

## 使い方

**ブラウザでそのまま使う (GitHub Pages):**

https://land-light.github.io/-/flashcards/

**ローカルで使う:**

```
index.html をブラウザで開く
```

ローカルサーバー経由で開く場合:

```
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

初回起動時にはサンプルデッキ（英単語＋穴埋めの例）が入っています。
`main` に push すると GitHub Actions (`.github/workflows/pages.yml`) が
`gh-pages` ブランチの `flashcards/` へ自動デプロイします
（`gh-pages` 上の既存アプリには触れません）。

## 主な機能

### 学習 (Anki と同じ流れ)
- **間隔反復学習 (FSRS-6)** — 現在の Anki の既定スケジューラと同じ
  [FSRS](https://github.com/open-spaced-repetition/fsrs-rs) を実装しています。
  記憶を Difficulty（難しさ）/ Stability（安定度）/ Retrievability（想起確率）の
  3 変数でモデル化し、大規模な学習ログでパラメータを最適化したアルゴリズムです。
  数式と既定パラメータは公式実装 `fsrs-rs` の `model.rs` に準拠しています。
  - 次の間隔は「思い出せる確率が目標保持率まで下がる日数」として計算されます
    （目標 90% なら 間隔 = 安定度）
  - **目標保持率**は設定で 85% / 90% / 95% から選べます（既定 90%）
  - 失敗した後の間隔も実データに基づいて算出されるため、
    30日間隔のカードを忘れた場合は 10分 → 約2日 から積み直します
- **4 段階評価** — 「もう一度 / 難しい / 普通 / 簡単」。各ボタンに次の復習間隔を表示。
- **学習ステップ** — 新規カードは 1分 → 10分 の学習ステップを経てから日単位の復習へ卒業。
- **回答の取り消し (Undo)** — 押し間違えても `Z` キーまたは ↩ ボタンで直前の回答を巻き戻せます。
- **1 日あたりの新規カード上限・復習上限** — デフォルト 20 枚 / 200 枚（設定で変更可）。
- **⚡直前モード** — 試験直前の一気読み用。デッキの「⚡直前」ボタンから、
  **復習の期限を無視して全カードをランダム順に出し続けます**（周回制で終わりなし）。
  評価は「できなかった / できた」の 2 択で、**通常の復習スケジュールには一切影響しません**
  （できなかったカードはその周回の後半にもう一度出ます）。

### カード作成 (ノートタイプ)
- **基本** — 表面（質問）と裏面（答え）。
- **基本と反転カード** — 1 回の入力で「表→裏」「裏→表」の 2 枚を作成。
- **穴埋め (Cloze)** — `{{c1::答え}}` で本文の一部を隠すカード。
  `{{c1::答え::ヒント}}` でヒント表示、`c1` `c2` … で 1 つの文から複数カードを生成。
  範囲選択して「穴埋め化」ボタンで記法を自動挿入できます。

### 画像・音声
- **画像の添付** — ファイル選択またはクリップボードから**貼り付け**（表・裏どちらにも可）。
- **音声の添付** — 音声ファイルの添付に加えて、**マイクでその場で録音**できます。
- **自動再生** — Anki と同じく、カード表示時に音声を自動再生（設定でオフ可）。`R` キーで再生し直し。
- メディア本体は IndexedDB に保存されるため、localStorage の容量制限（約5MB）に影響しません。

### 管理
- **デッキ管理** — 複数デッキの作成・名前変更・削除。新規/学習中/復習の枚数を一覧表示。
- **分野 (デッキ内の細分類)** — カードに「分野」を付けると、デッキの中をさらに細かく分けられます。
  デッキやノートタイプと同じく**プルダウンから選択**する方式で、
  一覧にない分野は「＋ 新しい分野を追加…」を選ぶと登録され、次回から選択肢に並びます
  （デッキの「⋯」→「＋ 分野を追加」からも登録できます）。
  **設定は任意**で、「（分野なし）」のままカードを作成できます。
  デッキ一覧の ▸ を押すと分野ごとの枚数が表示され、**分野単位で学習・直前モード**を実行できます。
  分野名の一括変更や分野の削除（カードは残ります）は分野行の「⋯」からできます。
- **タグ** — カードにタグを付けて、カード一覧から検索できます。
- **カードブラウザ** — 本文・タグの検索、モーダルでの編集（メディアの追加・削除も可）、削除。
- **統計** — カード状態の内訳、直近 14 日の学習履歴、今後 7 日の復習予定。
- **一括インポート** — タブ区切りテキスト（`表面 ⇥ 裏面`）を貼り付けて一括登録。
- **バックアップ** — 画像・音声も含めて JSON でエクスポート / インポート。
- **ダークモード対応** — OS の設定に自動追従。

### 通知 (リマインダー)
- 設定した時刻に「今日の復習カードが N 枚あります」と通知します（既定 20:00・オフ）
- アプリのアイコンに未処理枚数のバッジを表示します（対応環境のみ）
- **PWA 対応** — ホーム画面に追加するとアプリとして起動でき、オフラインでも開けます
- 仕組み上の制限: プッシュサーバーを使わないため、
  **ブラウザ（またはホーム画面のアプリ）を完全に終了している間は通知できません**。
  タブを開いたまま／バックグラウンドにしている間と、アプリを開いた時に通知します。
  iPhone / iPad は「ホーム画面に追加」したアプリでのみ通知を利用できます（iOS 16.4 以降）。

### キーボードショートカット

| キー | 動作 |
|---|---|
| `Space` / `Enter` | 答えを表示（表示中は「普通」で回答） |
| `1` 〜 `4` | もう一度 / 難しい / 普通 / 簡単 |
| `R` | 音声をもう一度再生 |
| `Z` | 直前の回答を取り消す |
| `Ctrl+Enter` | （追加画面で）カードを保存 |

## Google ログインで同期する

「設定 → Google 同期」で **Google アカウントにログインするだけ**で、
カード・画像・音声がクラウド (Firestore) に自動同期され、複数の端末で共有できます。
事前設定は不要です。

- 起動時とデータ変更の数秒後に自動で同期されます（手動の「今すぐ同期」も可能）
- 初回同期や両方の端末で変更があった場合は、デッキ・カードを **id 単位で統合（マージ）**します
  （同じカードは更新が新しい方を採用）。前回同期からどちらか一方だけが変わった場合は
  その側の内容を反映します（強制アップロード / 強制ダウンロードも可能）
- 注意: カードの削除は、両側変更のマージ時にはもう一方の端末から復活することがあります
- 同じ gh-pages 上の既存アプリ（会社法クイズなど）と**同じ Firebase プロジェクト**
  (`test-a7757`) を使用し、データは Firestore の `users/{uid}` 配下に保存されます

### 保存先の詳細と Firestore ルール

優先的に `users/{uid}/flashcards` サブコレクション（meta + chunk-N、容量制限なし）へ
保存します。Firestore のセキュリティルールがサブコレクションを許可していない場合は、
既存クイズアプリと同じ `users/{uid}` ドキュメントのフィールド (`fcData`) に自動で
フォールバックします（この場合 1MB 制限があるため、メディアが多いと上限に当たります）。

**同期が「Firestore のセキュリティルールで拒否されています」と表示される場合**は、
[Firebase コンソール](https://console.firebase.google.com/) → プロジェクト `test-a7757`
→ Firestore Database → ルール を開き、次の内容に置き換えて「公開」してください
（自分の `users/{自分のUID}` とその配下だけを読み書き可能にするルールです。
既存の会社法クイズアプリの同期にも同じルールが必要です）:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
      match /{document=**} {
        allow read, write: if request.auth != null && request.auth.uid == userId;
      }
    }
  }
}
```

## データの保存場所

カードデータはブラウザの **localStorage**、画像・音声は **IndexedDB** に保存されます。
Google 同期を使わない場合、ブラウザや端末を変えるとデータは引き継がれないため、
「設定 → バックアップ」から定期的に JSON（メディア込み）をエクスポートしてください。

## スケジューリングの仕組み (FSRS-6)

| 評価 | 学習中 / 再学習中 | 復習カード |
|---|---|---|
| もう一度 | 最初のステップ (1分) に戻る | 再学習へ (10分)。安定度が大きく下がる |
| 難しい | 現在のステップを繰り返す | 安定度の伸びを抑えた間隔 |
| 普通 | 次のステップへ (最後なら卒業) | 安定度から算出した間隔 |
| 簡単 | 即卒業 | 安定度をさらに伸ばした間隔 |

卒業後の間隔はすべて FSRS が記憶の安定度 S から計算します
（目標保持率 Rd に対して `間隔 = S/f × (Rd^(1/decay) − 1)`、`decay = −w20`）。
学習ステップは Anki の既定と同じ 1分 → 10分、再学習ステップは 10分 です。

「1 日」の境界は Anki と同様に午前 4 時です（深夜の学習が翌日扱いにならないように）。

既存のカードは、それまでの間隔と易しさから FSRS の記憶状態へ自動変換されます
（`fsrs-rs` の `memory_state_from_sm2` と同じ式）。
