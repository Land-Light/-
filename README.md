# ネームメーカー — 漫画ネーム制作ブラウザ

プロット(文章)を貼り付けると、コマ・吹き出し・棒人間を自動配置して漫画のネーム(下書き)を生成するブラウザアプリです。ビルド不要・単一の `index.html` だけで動きます。

## 使い方

1. `index.html` をブラウザで開く
2. 左ペインの「プロット用テンプレート」をコピーして自分のプロットを書く
3. プロット入力欄に貼り付けて「ネーム生成」を押す
4. 生成されたネームをドラッグで調整する

## プロットのテンプレート形式

```
# 1ページ目
## コマ1
太郎:おはよう!
花子:おはよう、今日も暑いね
## コマ2
太郎:そういえば宿題やった?
## コマ3
花子:……忘れてた
(放課後の教室)

# 2ページ目
## コマ1
太郎:しょうがないな、見せてやるよ
```

| 記法 | 意味 |
| --- | --- |
| `# 〜` で始まる行 | 新しい**ページ**の区切り |
| `## 〜` で始まる行 | 新しい**コマ**の区切り |
| `名前:セリフ` | 吹き出しになる(`:` / `:` どちらも可) |
| それ以外の行 | ナレーション・状況説明の枠になる |

## 生成ルール

- プロットの内容は解釈しません。テンプレートの区切りに従って機械的に配置します
- コマはページ内に右→左・上→下の読み順でデフォルトサイズ(1段2コマ)で均等配置
- セリフ1行ごとに縦書きの吹き出しを1つ作成(発話者名の小ラベル付き)
- コマ内のユニークな発話者の人数分だけ棒人間を配置(発話者が2人なら棒人間も2体)

## 手動調整

- **コマ / 吹き出し / 棒人間 / ナレーション枠**: ドラッグで移動
- **コマ右下の青い角**: ドラッグでサイズ変更
- **吹き出しの文字**: クリックしてその場で編集
- **選択して Delete キー**: 要素を削除
- ツールバーで表示倍率の変更とページ切り替えが可能

※「ネーム生成」を押し直すと手動調整はリセットされます。
