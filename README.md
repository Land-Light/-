# 🃏 暗記カード — 間隔反復学習アプリ

[Anki](https://apps.ankiweb.net/) を参考にした、ブラウザだけで動く暗記アプリです。
インストール・ビルド不要で、`index.html` を開くだけで使えます。

## 使い方

```
index.html をブラウザで開く
```

ローカルサーバー経由で開く場合:

```
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

初回起動時にはサンプルデッキ（英単語 5 枚）が入っています。

## 主な機能

- **間隔反復学習 (Spaced Repetition)** — Anki と同じ SM-2 ベースのアルゴリズム。
  覚えているカードほど復習間隔が伸び（1日 → 3日 → 1週間 → …）、
  忘れたカードは短い間隔で再出題されます。
- **4 段階評価** — 「もう一度 / 難しい / 普通 / 簡単」。各ボタンに次の復習間隔を表示。
- **学習ステップ** — 新規カードは 1分 → 10分 の学習ステップを経てから日単位の復習へ卒業。
- **デッキ管理** — 複数デッキの作成・名前変更・削除。新規/学習中/復習の枚数を一覧表示。
- **1 日あたりの新規カード上限** — デフォルト 20 枚（設定で変更可）。
- **カードブラウザ** — 検索・編集・削除。
- **統計** — カード状態の内訳、直近 14 日の学習履歴、今後 7 日の復習予定。
- **一括インポート** — タブ区切りテキスト（`表面 ⇥ 裏面`）を貼り付けて一括登録。
- **バックアップ** — JSON でエクスポート / インポート。
- **キーボードショートカット** — `Space`/`Enter` で答え表示、`1`〜`4` で評価。
- **ダークモード対応** — OS の設定に自動追従。

## データの保存場所

データはブラウザの **localStorage** に保存されます。サーバーは不要ですが、
ブラウザや端末を変えるとデータは引き継がれないため、
「設定 → バックアップ」から定期的に JSON をエクスポートしてください。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組みとナビゲーション |
| `css/style.css` | スタイル（ライト / ダークテーマ） |
| `js/srs.js` | 間隔反復スケジューラ（SM-2 ベース） |
| `js/store.js` | localStorage への永続化 |
| `js/app.js` | 画面描画とユーザー操作 |

## スケジューリングの仕組み

| 評価 | 学習中カード | 復習カード |
|---|---|---|
| もう一度 | 最初のステップ (1分) に戻る | 再学習へ。間隔 ×0.5、易しさ −0.2 |
| 難しい | 現在のステップを繰り返す | 間隔 ×1.2、易しさ −0.15 |
| 普通 | 次のステップへ (最後なら 1 日で卒業) | 間隔 × 易しさ (初期値 2.5) |
| 簡単 | 即卒業 (4 日) | 間隔 × 易しさ × 1.3、易しさ +0.15 |

「1 日」の境界は Anki と同様に午前 4 時です（深夜の学習が翌日扱いにならないように）。
