# 🃏 暗記カード — 間隔反復学習アプリ

[Anki](https://apps.ankiweb.net/) を参考にした、ブラウザだけで動く暗記アプリです。
インストール・ビルド不要で、`index.html` を開くだけで使えます。

## 使い方

**ブラウザでそのまま使う (GitHub Pages):**

https://land-light.github.io/-/

**ローカルで使う:**

```
index.html をブラウザで開く
```

ローカルサーバー経由で開く場合:

```
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

初回起動時にはサンプルデッキ（英単語＋穴埋めの例）が入っています。
`main` に push すると GitHub Pages が自動で配信します
（リポジトリの Settings → Pages で Source を「Deploy from a branch」の
`main` / `(root)` に設定しています）。

## 主な機能

### 学習 (Anki と同じ流れ)
- **間隔反復学習 (Spaced Repetition)** — SM-2 ベースのアルゴリズム。
  覚えているカードほど復習間隔が伸び（1日 → 3日 → 1週間 → …）、
  忘れたカードは短い間隔で再出題されます。
- **4 段階評価** — 「もう一度 / 難しい / 普通 / 簡単」。各ボタンに次の復習間隔を表示。
- **学習ステップ** — 新規カードは 1分 → 10分 の学習ステップを経てから日単位の復習へ卒業。
- **回答の取り消し (Undo)** — 押し間違えても `Z` キーまたは ↩ ボタンで直前の回答を巻き戻せます。
- **1 日あたりの新規カード上限・復習上限** — デフォルト 20 枚 / 200 枚（設定で変更可）。

### カード作成 (ノートタイプ)
- **基本** — 表面（質問）と裏面（答え）。
- **基本と反転カード** — 1 回の入力で「表→裏」「裏→表」の 2 枚を作成。
- **穴埋め (Cloze)** — `{{c1::答え}}` で本文の一部を隠すカード。
  `{{c1::答え::ヒント}}` でヒント表示、`c1` `c2` … で 1 つの文から複数カードを生成。
  範囲選択して「穴埋め化」ボタンで記法を自動挿入できます。

### 画像・音声
- **画像の添付** — ファイル選択またはクリップボードから**貼り付け**（表・裏どちらにも可）。
- **音声の添付** — 音声ファイルの添付に加えて、**マイクでその場で録音**できます。
- **自動再生** — Anki と同じく、カード表示時に音声を自動再生（設定でオフ可）。`R` キーで再生し直し。
- メディア本体は IndexedDB に保存されるため、localStorage の容量制限（約5MB）に影響しません。

### 管理
- **デッキ管理** — 複数デッキの作成・名前変更・削除。新規/学習中/復習の枚数を一覧表示。
- **タグ** — カードにタグを付けて、カード一覧から検索できます。
- **カードブラウザ** — 本文・タグの検索、モーダルでの編集（メディアの追加・削除も可）、削除。
- **統計** — カード状態の内訳、直近 14 日の学習履歴、今後 7 日の復習予定。
- **一括インポート** — タブ区切りテキスト（`表面 ⇥ 裏面`）を貼り付けて一括登録。
- **バックアップ** — 画像・音声も含めて JSON でエクスポート / インポート。
- **ダークモード対応** — OS の設定に自動追従。

### キーボードショートカット

| キー | 動作 |
|---|---|
| `Space` / `Enter` | 答えを表示（表示中は「普通」で回答） |
| `1` 〜 `4` | もう一度 / 難しい / 普通 / 簡単 |
| `R` | 音声をもう一度再生 |
| `Z` | 直前の回答を取り消す |
| `Ctrl+Enter` | （追加画面で）カードを保存 |

## Google ログインで同期する

「設定 → Google 同期」から Google アカウントでログインすると、カード・画像・音声を
**Google Drive のアプリ専用領域 (appDataFolder)** に保存し、複数の端末間で同期できます。
アプリ専用領域なので、Drive の他のファイルには一切アクセスしません。
同期はローカルとリモートの更新時刻を比べて新しい方を採用します
（強制アップロード / 強制ダウンロードも可能）。

### 初回セットアップ (Google クライアント ID の取得)

Google の仕様上、OAuth ログインには自分の「クライアント ID」が必要です（無料・約5分）。

1. [Google Cloud Console](https://console.cloud.google.com/) で新しいプロジェクトを作成
2. 「API とサービス → ライブラリ」で **Google Drive API** を検索して有効化
3. 「API とサービス → OAuth 同意画面」でアプリ名を設定
   （ユーザーの種類: **外部**、テストユーザーに自分の Gmail を追加）
4. 「API とサービス → 認証情報 → 認証情報を作成 → **OAuth クライアント ID**」で
   種類「**ウェブ アプリケーション**」を選択
5. 「承認済みの JavaScript 生成元」にアプリの URL
   （例: `https://land-light.github.io`）を追加
6. 発行されたクライアント ID（`〜.apps.googleusercontent.com`）を
   アプリの「設定 → Google 同期」に貼り付けて保存

同じ手順は、アプリの設定画面内にも表示されます。

## データの保存場所

カードデータはブラウザの **localStorage**、画像・音声は **IndexedDB** に保存されます。
Google 同期を使わない場合、ブラウザや端末を変えるとデータは引き継がれないため、
「設定 → バックアップ」から定期的に JSON（メディア込み）をエクスポートしてください。

## スケジューリングの仕組み

| 評価 | 学習中カード | 復習カード |
|---|---|---|
| もう一度 | 最初のステップ (1分) に戻る | 再学習へ。間隔 ×0.5、易しさ −0.2 |
| 難しい | 現在のステップを繰り返す | 間隔 ×1.2、易しさ −0.15 |
| 普通 | 次のステップへ (最後なら 1 日で卒業) | 間隔 × 易しさ (初期値 2.5) |
| 簡単 | 即卒業 (4 日) | 間隔 × 易しさ × 1.3、易しさ +0.15 |

「1 日」の境界は Anki と同様に午前 4 時です（深夜の学習が翌日扱いにならないように）。

# 📊 評価集計 — Excel の表から評価をつくる

`rating/` にある、もう 1 つのアプリです。Excel / CSV の表を読み込み、
**指定した行を除外したうえで**、残った対象者だけで評価（総合点・偏差値・順位・5 段階）を
計算します。こちらもインストール・ビルド不要で、外部ライブラリも使っていません。

**ブラウザでそのまま使う:** https://land-light.github.io/-/rating/

**ローカルで使う:** `rating/index.html` をブラウザで開く

## 使い方

**設定は要りません。ファイルを入れれば、その場で除外後の表が出ます。**

1. **読み込む** — `.xlsx` / `.csv` / `.tsv` をドラッグ＆ドロップ。
   シートと見出しの行は自動で判別します（表の上にタイトル行があっても大丈夫）。
2. **すぐに「除外後の表」が出る** — 判定に使う列も自動で選びます。
   「国籍」などの列に「日本」が入っていれば、**日本以外の行をすべて削除**します
   （日本 / 日本人 / 国内 / JP / Japan などを日本として扱い、空欄も削除します）。
   国籍の列が無ければ氏名の表記で判定します。
   判定に使った列は表から自動的に外れます（チェックを外せば残せます）。
   何をもとに何行削除したかは表の上に出て、
   「削除した行を確認する」でいつでも中身を確認できます。
3. **保存する** — 「Excel 用に保存 (CSV)」または「表をコピー」。

順位や偏差値の計算をしたいときだけ、下の
**「除外のしかたを変える・評価を計算する」**を開いてください。
除外条件の細かい調整、評価に使う列と重み、5 段階の付け方をここで設定できます。

## 計算の内容

| 項目 | 内容 |
|---|---|
| 総合点 | 選んだ項目 × 重み の合計 |
| 偏差値 | `50 + 10 ×` (総合点 − 平均) ÷ 標準偏差（標準偏差 0 のときは 50） |
| 順位 | 総合点の高い順。同点は同順位 |
| 相対評価 | 上位からの割合で 5 段階（既定 7 : 24 : 38 : 24 : 7 ％、変更可） |
| 絶対評価 | 偏差値のしきい値で 5 段階（既定 60 / 55 / 45 / 40、変更可） |

- **平均・標準偏差・順位・評価は、すべて除外後の対象者だけで計算されます。**
  除外した行が分布に影響することはありません。
- 「項目ごとに偏差値化してから合計する」を選ぶと、配点や難易度が違う項目
  （例: 100 点満点のテストと 10 点満点の提出物）を揃えてから合計します。
- 評価項目がすべて空欄の行は、結果表から自動的に除かれます。

## 氏名から候補を出すモード

国籍の欄が無い名簿のために、氏名を **表記** と **姓の一覧** で仕分けして
除外候補を提示する機能があります。判定できるのは表記であって国籍ではないため、
仕分けた結果は 1 件ずつチェックを外せる形で表示し、確定は利用者が行います。

| 仕分け | 内容 | 既定 |
|---|---|---|
| 日本語の氏名表記ではない | ハングル・アルファベット・キリル文字・簡体字など | 除外にチェック |
| カタカナ表記 | 外来名の可能性。日本国籍の方をカナ登録した名簿もある | 除外にチェック |
| 姓の一覧に無い | 珍しい日本の姓か、中国・韓国系の姓かは名前では区別できない。外している中韓系の姓に当たった場合はその姓を表示 | 除外にチェック |
| 姓の一覧にある | 通名を使う外国籍の方もここに入る | チェックしない |

列がほとんどカタカナ（フリガナ列）やローマ字の場合は、表記が手がかりにならないため
警告を出して判定を止めます。

### 中国・韓国系の主要な姓の扱い

姓の一覧は頻度の高い順に **43,092 件**あります。日本の姓を網羅的に集めると、
李・金・張・陳・王といった中国・韓国で使われる姓も「日本にも実在する姓」として
含まれてしまい、そのままでは漢字表記の氏名がまったく検出されません
（李は日本で 1,764 位、金は 1,050 位、張は 2,884 位、陳は 3,566 位）。

そこで **中国・韓国系の主要な姓 107 件を、既定で「日本の姓」から外しています。**
一覧から消したわけではなく外しているだけなので、いつでも戻せます。

- **まとめて戻す** — 「中国・韓国系の主要な姓 107 件を日本の姓から外す」の
  チェックを外すと、107 件すべてが元どおり日本の姓として扱われます。
- **1 件ずつ戻す** — 「外している姓を個別に戻す」を開くと、日本での順位つきで
  107 件が並びます。チェックを外した姓は日本の姓に戻り、その姓の方は候補に出なくなります。
  再びまとめて外しても、個別に戻した姓は戻したままになります。

外す対象は、日本で 1,000 位以内に入る姓を避けて選んでいます
（林は日本で 18 位、秦は 667 位なので外していません）。

### 姓の一覧のサイズ

「上位何件までを日本の姓とみなすか」も切り替えられます。
**狭めるほど検出は増えますが、珍しい姓の日本国籍の方も「一覧に無い」側へ入ります。**
全件のままなら、上の 107 件を外すことで漢字表記の姓を検出します。

| 一覧のサイズ | 挙動 |
|---|---|
| 全 43,092 件（既定） | 誤除外がほぼ無い。検出は「外している 107 件」に当たる姓のみ |
| 上位 10,000 件 | 一覧から漏れる日本の姓が増え始める |
| 上位 3,000 件 | 「勅使河原」など珍しい日本の姓も候補に出る |
| 上位 300 件 | 「東海林」「御手洗」なども候補に出る |

### 名前では分からないこと

- **通名（日本式の氏名）を使う外国籍の方は、どの設定でも検出できません。**
  一覧に載っている姓を使うためです。
- 帰化した方、国際結婚で外国姓になった日本国籍者、その子どもは、
  逆に「除外候補」側に出ます。
- したがって出力は「外国籍の方を除いたデータ」ではなく
  **「外国風の表記の氏名を除いたデータ」**です。用途に合うかご確認ください。

## 技術的なこと

- **ファイルは端末の外に出ません。** 読み込み・集計はすべてブラウザ内で完結し、
  どこにも送信しません。
- `.xlsx` は外部ライブラリを使わず、ブラウザ標準の `DecompressionStream` で
  ZIP を展開し、`DOMParser` でシートの XML を解析しています
  （Chrome 103 / Firefox 113 / Safari 16.4 以降）。
- CSV は UTF-8 と Shift_JIS を自動判別し、区切り文字（`,` / タブ / `;`）も推測します。
- 書き出す CSV には BOM を付けているので、Excel で開いても文字化けしません。

| ファイル | 役割 |
|---|---|
| `rating/index.html` | 画面の骨組み |
| `rating/css/style.css` | スタイル（ライト / ダークテーマ） |
| `rating/js/xlsx.js` | .xlsx / .csv の読み込み |
| `rating/js/surnames.js` | 日本の姓の一覧（頻度順 43,092 件）と姓の切り出し |
| `rating/js/namehint.js` | 氏名の表記・姓による仕分け |
| `rating/js/rating.js` | 表の整形・除外フィルタ・評価の計算 |
| `rating/js/app.js` | 画面描画とユーザー操作 |
